<h1>PixelMeasure</h1>
<p>This is a simple measuring tool to help new programmers visualize distances between pixels.</p>
<p>The main features present in this tool are:</p>
<ul>
     <li>A Ruler</li>
          <p>A simple ruler that will either sit on the left side, or top of the users screen, so they can visualize distance in px.</p>
     <li>A conversion tool</li>
          <p>A simple conversion program that will take distances in px, and then show it in either inches, centimeters, or milimeters.</p>
     <li>A reference for aspect ratios</li>
          <p>A window that shows the passed aspect ratio to the user</p>
     <li>A tool to show the distance between two points</li>
          <p>This class holds a small program that'll let users measure the number of pixels between two points that they click on.</p>
</ul>
